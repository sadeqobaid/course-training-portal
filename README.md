# Course Training Portal Reference Implementation

The accompanying beginner-first manual explains every command and file. The reference implementation uses PostgreSQL in Docker Compose, a NestJS API, a React frontend, and a deterministic Node worker.

## URLs after local startup

- Frontend: `http://localhost:5173`
- API health check: `http://localhost:3000/api/v1/health`
- Local email inbox: `http://localhost:8025`
